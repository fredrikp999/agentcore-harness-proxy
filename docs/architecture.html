Harness Proxy Architecture

A client reaches the AgentCore harness in eu-west-1 through Cloudflare Access and a streaming Lambda. The Lambda holds the only AWS permission, so callers never hold AWS keys.

Where a request can be stopped

LayerStatusReason
Cloudflare Accesslogin / 403No Allow policy or service token matches. The request never reaches AWS.

Lambda400Body is not JSON, message is empty or over 20,000 characters, harness is unknown, or session_id is under 33 characters.
